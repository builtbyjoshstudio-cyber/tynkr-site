03

How your data lives.

Open formats

Ledger writes one JSON file per year of transactions, one per month for budgets, and a small file each for accounts, bills, debts, sinking funds and settings. Open any year in a text editor, diff it, script against it — it’s just data. Turn on optional encryption and the same files are saved encrypted instead.

No proprietary database. No export fee. No account standing between you and your own files. If Ledger disappeared tomorrow, this folder still works.

Documents/Tynkr Ledger/ ├─ transactions-2026.json · this year’s transactions ├─ transactions-2025.json ├─ budget-2026-03.json · one per month ├─ net-worth-2026.json · monthly snapshots ├─ accounts.json ├─ bills.json ├─ debt.json ├─ sinking-funds.json ├─ goals.json ├─ config.json · budget plan, categories, rules └─ attachments/ · receipts you attach

Fair questions.

FAQ
Does Ledger connect to my bank?

No. Ledger never asks for bank credentials and makes no network requests to financial institutions. You import transactions by downloading a CSV, OFX or QFX file from your bank’s website and opening it in Ledger.

Where is my financial data stored?

In JSON files in a folder you choose on your own machine — one file per year of transactions, plus files for budgets, bills, debts and settings. You can open, back up, or move them with any tool. If you turn on optional encryption, the files are encrypted with your password.

Is there a subscription?

No. Ledger is a one-time purchase when it launches. Bug fixes are always free; major version upgrades are a separate purchase. There is no account and no recurring billing.

Does it work offline?

Yes. The app needs no internet connection and makes no network calls of its own. Updates arrive through the Microsoft Store when you're online. Airplane mode is a supported configuration.

Can I get my data out?

It was never locked in. Your data is already JSON on your disk (or encrypted JSON, if you turn encryption on), and you can back it all up as a single file anytime. If you stop using Ledger, your files keep working with anything that reads JSON.
